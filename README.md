# DouyinFilter Android V0.7.5

一个基于本地视觉模型的 Android 个人实验项目：在抖音中自动切换视频、对当前视频画面进行多帧本地分析，在满足设定条件时尝试分享给指定联系人。

> 当前公开说明对应 **V0.7.5**。项目仍处于个人实验阶段，不保证适配所有设备、抖音版本或系统环境。

## 项目用途

本项目主要用于学习和验证以下技术：

- Android MediaProjection 屏幕画面采集
- Android AccessibilityService 无障碍自动化
- ONNX Runtime Android 本地模型推理
- SigLIP2 图像分类模型的移动端部署
- OpenAI CLIP 的图文特征能力及视觉分支移动端部署
- 多帧视频采样、模型结果融合和自动化状态机

所有视觉分析均在设备本地完成。程序不会将截取的视频画面上传到本项目作者的服务器。

## 使用的第三方模型

本项目当前构建流程会使用：

1. `prithivMLmods/siglip2-x256p32-explicit-content`，使用 `checkpoint-1656`，用于图像显式内容分类中的 `Enticing or Sensual` 类别判断。
2. `openai/clip-vit-base-patch32`，用于构建女性 / 男性 / 无明显人物的辅助视觉判断。

为适配 Android，本项目在构建阶段将需要的模型转换为 ONNX FP16，并针对实际推理需求进行封装。第三方模型、模型权重、论文、商标及相关内容的权利归各自权利人所有；本项目不声称拥有第三方模型的知识产权。使用、修改或再分发相关模型时，请自行查阅并遵守各模型原始仓库的许可证、Model Card 和使用要求。

## 隐私说明

- 视频画面通过 Android MediaProjection 在本机内存中获取并用于模型推理。
- 模型输入截图不会由本项目主动保存到手机相册。
- 程序会保留有限大小的本地运行诊断文本日志，用于排查模型耗时、自动化步骤和异常状态；日志不用于云端分析。
- 分享行为最终由抖音客户端执行。

## 当前识别流程概览

当前版本以多帧方式分析视频：目标采样 18 帧，先使用 SigLIP2 获取各帧的视觉分类分数，再从代表帧中使用 CLIP 辅助判断人物主体，最后由本项目自己的多帧规则得到 `positive / border / negative / insufficient` 结果。只有 `positive` 才进入分享自动化流程。

## 构建说明

模型文件不需要手工提交到源码目录。GitHub Actions 中的构建脚本会从原始模型来源获取模型并生成 Android 使用的 FP16 ONNX 文件，然后再编译 APK。
